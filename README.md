## Обзор

Этот проект — учебный **Telegram-бот для знакомств**, в котором я пробую спроектировать не только бота, но и «настоящую» серверную часть с раздельными сервисами и рейтингом анкет.

Основная идея: у каждого пользователя есть анкета, которую видят другие. Они могут её лайкать или пропускать, при взаимных лайках образуется мэтч, после чего можно переписываться.  
Порядок показа анкет не случайный — он строится по **трёхуровневой системе рейтинга**:

- **Уровень 1 — первичный рейтинг**  
  Оценивает саму анкету: возраст, пол, город, интересы, насколько профиль заполнен и сколько фотографий загружено. Также сюда входят базовые настройки пользователя (кого он ищет: пол, возрастной диапазон, город).

- **Уровень 2 — поведенческий рейтинг**  
  Учитывает, как другие пользователи ведут себя с этой анкетой: сколько она набрала лайков, насколько часто её скипают, как часто из лайков получаются мэтчи и начинаются диалоги, и в какие периоды суток анкета наиболее активна.

- **Уровень 3 — комбинированный рейтинг**  
  Сводит вместе первичный и поведенческий рейтинги по весовой формуле и добавляет дополнительные бонусы, например за участие в реферальной системе (приглашение друзей).

С технической стороны я закладываю такие компоненты:
- отдельный сервис, который отвечает за расчёт рейтингов и запускает пересчёты в фоне через **Celery**;
- **Redis** как быстрый кэш: туда складываются уже отсортированные очереди анкет, чтобы бот мог быстро поднимать следующую пачку карточек;
- брокер сообщений (**Kafka**, **RabbitMQ** или аналог) для того, чтобы передавать события (лайки, мэтчи, сообщения) между сервисами не напрямую, а через очередь;
- файловое хранилище формата **S3** (локально — **Minio**) для фотографий, а в базе хранить только ссылки и метаданные;
- сбор метрик и логов из сервисов, чтобы можно было отслеживать состояние системы и поведение пользователей.

## Ключевые пользовательские сценарии

- **Старт и регистрация**  
  Пользователь впервые пишет боту (`/start`). Бот привязывает Telegram-аккаунт к записи в базе и создаёт заготовку профиля.

- **Заполнение профиля (анкеты)**  
  Бот по шагам собирает данные: имя, возраст, пол, город, интересы, описание и фотографии. По этим данным и полноте заполнения профиля формируется вклад в первичный рейтинг.

- **Получение ленты анкет**  
  Когда пользователь переходит к просмотру, бот запрашивает для него очередь анкет. Она формируется сервисом рекомендаций с учётом комбинированного рейтинга и настроек фильтра (кого мы ищем по полу, возрасту и географии).

- **Лайк / пропуск**  
  На каждой карточке можно поставить лайк или пропустить. Эти события записываются в отдельный сервис и через очередь сообщений передаются в сервис рейтинга, где используются при пересчёте поведенческого рейтинга.

- **Мэтч**  
  Если два пользователя лайкнули друг друга, создаётся мэтч. Оба получают уведомление от бота. Этот факт тоже попадает в статистику и влияет на рейтинги.

- **Переписка**  
  Для каждой пары с мэтчем создаётся диалог. Сообщения идут через бота, а события уровня «начался диалог», «пришло новое сообщение» используются для дополнительной аналитики и оценки активности.

## Этап 2: Базовая функциональность (MVP)

В репозитории добавлен базовый бот-сервис с интеграцией Telegram Bot API и первичной регистрацией по команде `/start`.

Что реализовано:
- сервис бота (`python-telegram-bot`);
- обработчики `/start`, `/profile`, `/cancel`, `/help`;
- регистрация пользователя по `telegram_id` (берётся из Telegram update);
- пошаговое заполнение анкеты: имя, возраст, пол, город;
- сохранение/обновление пользователя и анкеты в SQLite (`data/bot.sqlite3`).

### Быстрый запуск

1. Создать и активировать виртуальное окружение.
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Установить токен бота:

```bash
# PowerShell
$env:TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
```

4. Запустить сервис:

```bash
python -m bot.main
```

После `/start` бот создаёт или обновляет запись пользователя по Telegram ID и запускает сбор базовой анкеты.
